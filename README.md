# BC1--Fundamentos-de-programacion-EJERCICIOS-
8. Datos personales — DatosPersonales —
Crea un programa que imprima tu nombre y edad en la consola.
9. Variables y tipos de datos — VariablesTiposDatos —
Declara variables de tipo int, double, boolean y String, asígnales valores y muéstralos en la consola.
10. Conversión de tipos — ConversionTipos —
Convierte un valor double a int usando cast y guárdalo en una variable llamada entero. Imprime el valor convertido.
11. Nombre y edad — NombreEdad —
Solicita al usuario su nombre y edad y muestra un mensaje personalizado.
12. Área de un círculo — AreaCirculo —
Solicita el radio y calcula el área de un círculo.
13. Conversión de Celsius a Fahrenheit — CelsiusAFahrenheit —
Solicita una temperatura en grados Celsius y conviértela a Fahrenheit.
14. Área de un rectángulo — AreaRectangulo —
Solicita la base y la altura y calcula el área del rectángulo.
15. Promedio de tres números — PromedioTresNumeros —
Solicita tres números y calcula su promedio.
16. Vocal en mayúscula — VocalMayuscula —
Lee una vocal y muéstrala en mayúscula. Si no es una vocal, informa de que la entrada no es válida.
17. Par o impar — ParImpar —
Solicita un número y determina si es par o impar utilizando if.
18. Mayor de tres números — MayorDeTres —
Lee tres números y muestra cuál de ellos es el mayor.
19. Mayoría de edad — MayorDeEdad —
Lee el año de nacimiento y muestra si la persona es mayor de edad o no.
20. Día de la semana — DiaSemana — 
Solicita un número del 1 al 7 y muestra el día correspondiente utilizando switch.
21. Datos del usuario — DatosUsuario —
Solicita nombre completo, edad, altura y si estudia actualmente mediante Scanner. Muestra los datos con System.out.printf y controla errores básicos de entrada mediante try-catch.
22. Números del 1 al 10 con for — NumerosDel1Al10F —
Muestra los números del 1 al 10 utilizando un bucle for.
23. Números del 1 al 10 con while — NumerosDel1Al10W —
Muestra los números del 1 al 10 utilizando un bucle while.
24. Números del 1 al 10 con do-while — NumerosDel1Al10D —
Muestra los números del 1 al 10 utilizando un bucle do-while.
25. Calculadora — Calculadora —
Solicita dos números enteros y muestra su suma, resta, multiplicación y división, teniendo en cuenta la división por cero.
26. Edad y 100 años — EdadCien —
Solicita el año de nacimiento y el año actual. Calcula la edad aproximada, indica cuánto falta para cumplir 100 años y muestra un mensaje especial si ya los ha cumplido o superado.
27. Días de un mes — DiasMes —
Solicita un número de mes y muestra el número de días que tiene. Para el mes 12, la salida debe indicar: «Diciembre tiene 31 días».
28. Suma de números hasta negativo — SumaNumeros —
Solicita números hasta que el usuario introduzca uno negativo. Al final, muestra la suma total de los números anteriores.
29. Divisores de un número — Divisores —
Solicita un número y muestra sus divisores.
30. Número primo — Primo —
Dado un número entero, determina si es primo o no.
31. Sucesión de Fibonacci — Fibonacci —
Solicita el orden por consola y muestra la sucesión de Fibonacci.
32. Suma de un array — Suma —
Calcula la suma de los elementos de un array de cinco enteros.
33. Contar números pares — ContarPares —
Cuenta cuántos números pares hay en un array.
34. Mostrar un array invertido — MostrarInvertidos —
Muestra en orden inverso los elementos de un array de enteros.
35. Buscar un elemento — BuscarElemento —
Muestra la posición de un elemento en un array.
36. Array de nombres — Nombres —
Solicita tres nombres, almacénalos en un array y muéstralos recorriendo el array.
37. Máximo y posición — EncontrarMaximo —
Encuentra el valor máximo de un array de enteros y también su posición.
38. Array de números de lotería — Loteria —
Guarda en un array de seis posiciones números aleatorios entre 1 y 49 para un sorteo de lotería. Como mejora opcional, muestra los números ordenados.
39. Invertir una cadena — InversoCaracteresString —
Lee un String y muestra su contenido por pantalla en orden inverso, carácter a carácter.
40. Contar un carácter — ContarCaracter —
Lee una cadena y un carácter, y cuenta mediante contarVecesCaracter cuántas veces aparece el carácter.
41. Método para sumar un array — SumaArray —
Utiliza un array de 10 enteros y escribe un método que calcule y retorne la suma de sus elementos.
42. Suma de la diagonal principal — SumaDiagonal —
Utiliza un array bidimensional de 3 × 3 y escribe un método que calcule y retorne la suma de los elementos de la diagonal principal.
43. Métodos para una matriz — Matriz —
Utiliza un array bidimensional de 3 × 3 y crea los métodos sumaElementos, maximoElemento y minimoElemento.
44. Validar una hora — ValidarHora —
Lee horas, minutos y segundos y valida, mediante el método esHoraValida, que los valores sean correctos.
45. Clase Animal — Animal —
Crea una clase con atributos como nombre, especie y edad, e incluye un método que imprima sus características.
46. Clase Estudiante — Estudiante —
Crea una clase con atributos como nombre, edad y carrera, e incluye un método que imprima un saludo personalizado.
47. Clase Libro — Libro —
Crea una clase con atributos como título, autor y añoPublicación, e incluye un método que imprima los detalles del libro.
48. Clase Coche — Coche —
Crea una clase con atributos como marca, modelo, año, km y litros. Incluye métodos para encender, apagar, conducir, repostar y mostrar información.
49. Clase CuentaBancaria — CuentaBancaria —
Crea una clase con atributos como titular, saldo y numeroCuenta, e incluye métodos para depositar, retirar y mostrar el saldo.
50. Gestor de notas — GestorNotas —
Crea un programa para gestionar hasta 10 estudiantes mediante arrays paralelos de nombres y notas. Incluye un menú para registrar estudiantes, calcular el promedio, mostrar estadísticas, buscar estudiantes y salir. Controla que no se supere el límite y que no se realicen cálculos cuando no haya estudiantes registrados.
